# AuthenAI Saved Models Directory

This directory stores exported deep learning model weights and ONNX runtime graphs:

- `document_ela_efficientnet.onnx`: Compact ONNX model for document patch tampering classification.
- `facenet_landmarks.onnx`: 68-point 3D facial landmark mesh extractor.
- `audio_vocoder_detector.pt`: PyTorch weights for neural vocoder acoustic boundary detection.
